Called by the page templates, never from markdown: {{}} `page.slug` is the file name without its extension, so `ayesha.md` finds the rows whose `course` column is `ayesha`. Nothing has to be written into a course page to give it a price, and there is no name that can drift out of step with the file it belongs to. It has to be the template rather than a call in the markdown, because a component called from markdown cannot see `page` at all — the build fails with "Variable `page` is not defined". The cost is that this text sits outside `page.content` and so never reaches the search index. A row with a `duration` is part of a tier grid and renders as a table of duration against group size. A row without one is a named rate and renders as "label: € amount". A course may have both, and the private lessons do. A course with no rows renders nothing at all, which is the normal case: most course pages carry no price. That is why there is no guard here for a name that matches nothing — an unknown course is indistinguishable from a course with no prices. `tools/check-prices.mjs` covers the other direction instead, failing when a row names a course page that does not exist. Adjacent cells are separated by a space even though HTML does not need one: `xy` reads as the single word "xy" once tags are stripped, which matters wherever this text is scraped or read aloud. #} {% component prices(course) %} {%- set all = load_data(path="prices.csv") -%} {%- set rows = [r for r in all["records"] if r[0] == course] -%} {%- set flat = [r for r in rows if r[4] == ""] -%} {%- set tiered = [r for r in rows if r[4] != ""] -%} {#- Tier grids come before named rates.
