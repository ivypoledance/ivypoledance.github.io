Called from a course page's markdown, where the prices belong: {{ }} The page names a block, never an amount. Every amount lives in prices.csv, so a rate shared by several courses is one row and changing it is one edit; the euro sign and its spacing live here, so the price format is also one edit sitewide and no amount in the CSV can carry a comma that would split a field. It is called from markdown rather than appended by the page template so that the text lands in `page.content`, which is what the search index is built from. Appended markup is invisible to search. A row with `duration` set is part of a tier grid and renders as a table of duration against group size. A row without one is a named rate and renders as "label: € amount". A block mixing the two is a mistake in the data, and shows as both. A block name that matches nothing is a typo, and must stop the build rather than quietly render no price. Tera has no assert, and `{% set %}` accepts an out-of-range index without complaint — only rendering an undefined value raises. So the guard below renders one, deliberately: the build then fails naming this file, this line, and `price_block_not_found_in_prices_csv`. The markup is emitted flush left and on as few lines as possible, because a line indented by four spaces would be turned into a code block by the markdown parser rather than into HTML. Adjacent cells are separated by a space even though HTML does not need one.
